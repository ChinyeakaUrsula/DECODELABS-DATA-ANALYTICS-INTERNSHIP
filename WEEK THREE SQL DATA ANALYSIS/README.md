DECODELABS Week Three – SQL Data Analysis
Project Overview
This project is the third project in my DECODELABS Data Analytics Internship. The objective was to use SQL to query an e-commerce dataset and extract meaningful business insights.
The dataset contains 1,200 order records covering customer orders, products, quantities, prices, payment methods, order statuses, and other transaction details.
Objectives
The project focused on:
•	Writing SQL SELECT queries
•	Filtering data using WHERE
•	Sorting results using ORDER BY
•	Grouping data using GROUP BY
•	Performing aggregations using COUNT, SUM, and AVG
•	Extracting business insights from transactional data
Tools Used
•	SQL Server Management Studio (SSMS)
•	Microsoft SQL Server
•	SQL
•	CSV dataset
SQL Analysis Performed
The analysis included:
1.	Displaying all records
2.	Selecting specific columns
3.	Filtering orders based on quantity
4.	Identifying high-value orders
5.	Sorting orders by total price
6.	Identifying the lowest-value orders
7.	Counting orders by product
8.	Calculating total sales by product
9.	Calculating average order value by product
10.	Calculating overall order count, total sales, and average order value
11.	Counting orders by order status
12.	Calculating total sales by order status
13.	Calculating total sales by payment method
14.	Calculating average order value by payment method
15.	Identifying the top 10 customers by total sales
Key Findings
•	The dataset contains 1,200 orders with total sales of 1,264,761.96.
•	The overall average order value was 1,054.97.
•	Chair generated the highest total sales at 195,620.11.
•	Printer had the highest number of orders, with 181 orders.
•	Laptop had the highest average order value at 1,110.56.
•	Cancelled orders had the highest order count, with 250 orders.
•	Cancelled orders also had the highest associated sales value at 276,396.21.
•	Credit card transactions generated the highest total sales at 263,847.63.
•	Credit card transactions also had the highest average order value at 1,127.55.
•	Customer C38840 generated the highest total sales among individual customers at 5,723.23.
•	The highest individual transaction value was 3,456.40, while the lowest was 11.39.
Business Insights
The analysis demonstrates that different products lead different performance measures. While Printer had the highest order frequency, Chair generated the highest total sales, and Laptop recorded the highest average order value.
The high sales value associated with cancelled orders highlights an area that may require further investigation, particularly around cancellation reasons and potential revenue loss.
Payment method analysis showed that credit card transactions performed strongest in both total sales and average order value.
Customer-level analysis also identified high-value customers who could be considered for targeted retention and engagement strategies.
