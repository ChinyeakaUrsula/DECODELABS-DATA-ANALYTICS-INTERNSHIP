DECODELABS Project 4 – Data Visualization

Project Overview

This project is part of the DECODELABS Data Analytics Internship Program and focuses on transforming an e-commerce dataset into an interactive Power BI dashboard.

The objective was to create clear and meaningful visualizations that communicate sales performance, order patterns, product performance, and key business insights.

Objective

The main objectives of this project were to:

* Create effective data visualizations using Power BI.
* Select appropriate chart types for different business questions.
* Present key performance indicators clearly.
* Enable users to interact with the dashboard using slicers.
* Communicate meaningful business insights through data storytelling.

Dataset

The dataset contains 1,200 e-commerce orders and includes information such as:

* Order ID
* Date
* Customer ID
* Product
* Quantity
* Unit Price
* Shipping Address
* Payment Method
* Order Status
* Tracking Number
* Items in Cart
* Coupon Code
* Referral Source
* Total Price

Before visualization, the dataset was reviewed and prepared in Power BI Power Query. Missing Coupon Code values were replaced with "NO COUPON", and the appropriate data types were confirmed for the analysis.

Tools Used

* Microsoft Power BI
* Power Query
* DAX

Dashboard Features

The dashboard contains four KPI cards:

* Total Sales
* Total Orders
* Average Order Value
* Cancelled Orders

Visualizations

The following visualizations were created:

1. Total Sales by Product– compares sales performance across products.
2. Sales Trend Over Time – shows the movement of total sales across the available years.
3. Orders by Payment Method – shows the distribution of orders across payment methods.
4. Orders by Order Status – highlights the distribution of orders according to their status.

Interactive Slicers

Two slicers were included to allow users to interact with the dashboard:

* Year
* Product

These slicers allow users to explore the dashboard dynamically and analyse performance for specific years or products.

Key Insights

* The dataset contains 1,200 orders with total sales of approximately $1.26 million.
* Printer recorded the highest number of orders among the products.
* Chair generated the highest total sales among the products.
* The dashboard shows differences in sales performance across the available years.
* 250 orders were cancelled, highlighting cancellations as an area that may require further investigation.
* The interactive Year and Product slicers allow users to drill into specific periods and products for more focused analysis.

Project Outcome

The completed dashboard transforms raw e-commerce data into an interactive and easy-to-understand business intelligence report.

It provides a concise view of sales performance, order behavior, product performance, and order status while allowing users to explore the data through interactive filters.
